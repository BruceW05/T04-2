# Volt Home Appliances — Website

A three-page website (Home, Televisions, About Us) built to meet the activity requirements:

- Single top navigation menu that swaps between the three pages using JavaScript (no page reloads).
- Logo in the top-left corner, always clickable to return to Home.
- Nav links give mouse-over feedback (background colour change) and show which page is currently active.
- Styling lives in `styles.css`, using a colour palette matched to the logo (cream/gold, orange, brown).
- Footer includes the year (set dynamically via JavaScript), your name, and a GenAI acknowledgement.
- Placeholder content relates to appliance energy consumption in the Australian market (energy rating labels, estimated running costs, etc.) — all figures are illustrative, not real data.

## Files

- `index.html` — page markup for all three pages (as `<section>` elements toggled by JS)
- `styles.css` — all styling
- `script.js` — navigation logic (page switching, active state, logo-to-home, footer year)
- `images/logo.png` — site logo
